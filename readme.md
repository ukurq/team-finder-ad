# TeamFinder

Платформа, на которой разработчики, дизайнеры и другие специалисты находят единомышленников
для совместной работы над pet-проектами: публикуют идеи, собирают команду и откликаются на
чужие предложения.

## Возможности

- регистрация и вход по email, профиль с аватаркой, контактами и описанием;
- публикация проектов, статусы «открыт» / «закрыт», участие в проектах;
- необходимые навыки проекта: добавление и удаление без перезагрузки страницы, автодополнение,
  создание новых навыков на лету;
- фильтрация проектов по навыку (`/projects/list/?skill=<название>`);
- список участников платформы, смена пароля, админ-панель (`/admin/`).

## Технологии

Python 3.10+, Django 5.2, PostgreSQL 16 (Docker), Pillow, python-decouple.

## Структура проекта

| Каталог     | Назначение                                                                  |
|-------------|-----------------------------------------------------------------------------|
| `core`      | общие компоненты: валидаторы, вспомогательные функции (пагинация)           |
| `users`     | пользователи, регистрация и вход, профиль, смена пароля, список участников  |
| `projects`  | проекты, навыки, участие в проектах                                         |
| `templates` | HTML-шаблоны                                                                |
| `static`    | CSS, JS, шрифты, изображения                                                |

## Запуск проекта

### 1. Виртуальное окружение и зависимости

```bash
python -m venv venv
```

Активация окружения:

- Windows (PowerShell): `venv\Scripts\Activate.ps1`
- Windows (cmd): `venv\Scripts\activate`
- Linux/macOS: `source venv/bin/activate`

```bash
pip install -r requirements.txt
```

### 2. Настройка `.env`

Скопируйте пример и при необходимости измените значения:

```bash
cp .env_example .env
```

| Переменная              | Назначение                                                                        |
|-------------------------|-----------------------------------------------------------------------------------|
| `DJANGO_SECRET_KEY`     | секретный ключ Django (для продакшена сгенерируйте свой)                          |
| `DJANGO_DEBUG`          | режим отладки, `True` для разработки                                              |
| `DJANGO_ALLOWED_HOSTS`  | разрешённые хосты через запятую, по умолчанию `localhost,127.0.0.1`               |
| `POSTGRES_DB`           | имя базы данных                                                                   |
| `POSTGRES_USER`         | пользователь PostgreSQL                                                           |
| `POSTGRES_PASSWORD`     | пароль пользователя PostgreSQL                                                    |
| `POSTGRES_HOST`         | адрес сервера БД (`localhost` при запуске через docker compose)                   |
| `POSTGRES_PORT`         | порт БД, по умолчанию `5432`                                                      |

Если порт 5432 на компьютере занят, поменяйте левую часть пары портов в
`docker-compose.yml` (например, `"5433:5432"`) и укажите тот же порт в `.env`.

### 3. База данных

```bash
docker compose up -d
```

Данные хранятся в Docker volume `postgres_data` и сохраняются при перезапуске контейнера.
Остановить БД: `docker compose down`.

### 4. Миграции и тестовые данные

```bash
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
```

`seed_demo` создаёт трёх тестовых пользователей (`anna@example.com`, `boris@example.com`,
`vera@example.com`) и по одному проекту у каждого; пароль указан в
`projects/management/commands/seed_demo.py`.

### 5. Запуск

```bash
python manage.py runserver
```

Сайт: http://localhost:8000, админка: http://localhost:8000/admin/.

### Тесты

```bash
python manage.py test
```
